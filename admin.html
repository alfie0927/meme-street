Accounts

Loading…

Adding MB credits the player's cash (recorded as MB "added by an admin", which counts as money put in, so it never lifts their return or rank) and tells them, with your note. Taking back removes only free cash. At most 1,000,000 MB at a time. A reset ends all of that player's logins and shows a temporary password once. Tell it to them privately; they should change it on their profile page. Addresses are stored only as salted tags, so you can see which accounts share one, not what it is.

Email and mail

Loading…

Email addresses make passwords recoverable and stop one person running many accounts (each address belongs to one account). Set the email_mode setting to off, optional or required. With no SMTP server configured (see mailer.py) nothing is sent: the message, code included, appears in the list above so you can hand a code to a tester yourself.
