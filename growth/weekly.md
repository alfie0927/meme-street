# Weekly numbers (every Monday)

The growth plan's "How we will know": one row a week, so each source is judged by finished games and new
accounts, not by views. Sources: the visit log (`tools/visits.py`, once it is on), sign-ups by source (the admin
panel), the Daily Chart's own stats, and Instagram insights (`lab/insights.py`).

**The number that matters:** people, house bots excluded, who finished a Daily Chart or made a trade this week.
